# MultiApp 软件更新

从 **0.1.0-beta.5** 起，可以在 MultiApp 内检查和安装新版。

## 第一次升级

beta.4 及更早版本没有内置更新器，需要到 [GitHub Releases](https://github.com/sunholdshen/multi-app/releases) 下载一次 beta.5 或更新版本，退出 MultiApp 后将新版拖入「应用程序」并替换。已有副本、数字图标设置及账号文件会保留。

## 在应用内升级

1. 打开「关于 MultiApp」，点击 **检查更新…**；也可以使用屏幕顶部「MultiApp → 检查更新…」。
2. 有新版时查看版本和更新说明，选择下载安装。
3. 下载和校验完成后选择安装并重新启动，更新器会替换 MultiApp。

安装目录需要管理员权限时，macOS 可能要求本机认证；在系统弹窗中操作即可。

## 自动更新设置

「关于 MultiApp → 软件更新」提供两个开关：

- **自动检查更新**：默认开启，每天检查一次；可以关闭并改为手动检查。
- **自动下载并在退出时安装**：默认关闭。开启后会在后台准备更新，并在正常退出 MultiApp 时安装；需要授权时会提示。

正在创建、重建或修改副本时，更新流程会等待当前操作完成。更新提示或下载进行期间暂时不能开始新的副本修改操作。已打开的飞书可以继续运行。

## 更新范围

此功能更新 **MultiApp 管理器**。已有飞书副本、序号和账号数据保持原样。管理器更新本身不会重新签名飞书副本；要更新飞书客户端版本，仍先更新官方飞书，再使用「保留数据并重建」。要应用新版图标样式，仍在副本的「图标与序号」中操作。

更新通过 GitHub 下载，安装包会自动匹配当前 MultiApp 的架构。更新清单与下载包都进行签名验证，包在解压前校验；验证失败会停止安装。

## 下载或检查失败

网络不通时可以稍后重新检查；也可从 [GitHub Releases](https://github.com/sunholdshen/multi-app/releases) 手动下载替换。若提示签名校验失败，请重新下载官方发布包，不要关闭校验。

当前发布仍为本地签名预览版，尚未 Apple 公证。首次手动安装请参阅 [首次打开图文指南](first-launch.md)。更新签名用于验证发布包来源，与 Apple 公证是不同的机制。
